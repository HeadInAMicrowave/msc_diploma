# seed_v2.txt -- expanded seed corpus for the toxic-span teacher
#
# FORMAT
#   One raw chat message per line. Lines starting with '#' are structure, not
#   data: the teacher client must skip them. A category header is a '#' line
#   whose first token is the category name in square brackets, for example
#       # [DIRECTED_HOSTILITY_SEPARABLE]  (expected: ...)  ~60
#   and it sets the AUTHOR-INTENT CATEGORY for the data lines that follow.
#   The brackets are deliberate: any other '#' line is free prose, so a
#   comment that happens to begin with a category name cannot be mistaken
#   for a header. (This exact mistake was caught in testing.)
#
# WHAT THE CATEGORY IS -- AND IS NOT
#   The category is NOT a label. The teacher decides the labels (the <del>
#   spans) per teacher_prompt.md and annotation_policy.md. The category
#   records what the author *expected* the branch to be. It serves two jobs:
#     1. Stratified train/test split and per-category evaluation, so the
#        results chapter can report "how does the tagger do on swear-free
#        hostility vs obfuscated profanity vs traps" separately.
#     2. Disagreement QC. When the teacher's output contradicts the
#        author's expectation (e.g. it tags a line filed under CLEAN, or
#        leaves a FUSED line untouched), that row is worth inspecting.
#        The per-category author-vs-teacher disagreement rate is itself a
#        reportable number and an honest measure of how contestable the
#        boundary is.
#   The client should carry the active category into each emitted JSONL row.
#
# WEIGHTING
#   The headline capability -- swear-free hostility aimed at a person, with
#   keepable content alongside -- is deliberately the largest class, and it
#   is paired with an equally large PLAY_CRITICISM contrast class that reuses
#   the same negative vocabulary aimed at plays and situations. That pairing
#   is what teaches the person-vs-play line instead of "negative word = toxic".
#
# EXCLUDED ON PURPOSE
#   Identity-based slurs (racial, ethnic, sexual-orientation, etc.) are not
#   hand-authored here. Authoring them is inappropriate and unnecessary: the
#   Jigsaw-trained gate already covers identity attacks, and if slur coverage
#   is needed for the tagger it should be sourced from an existing annotated
#   corpus (Jigsaw, SemEval Toxic Spans), not written by hand.
#
# ONE SECTION REMAINS REVIEW-FLAGGED (see note at it): SARCASM_REVIEW.
#   GROUP_DIRECTED has been ruled (toxic, remove) and is now a normal class.
#
# Register: MOBA / team-shooter chat (lanes, baron, dragon, sites, flags),
# mixed casing and punctuation, as real chat is.
